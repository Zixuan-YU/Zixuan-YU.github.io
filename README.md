# Avery Yu Personal Website

This repository contains Avery Yu's personal academic website.

The site uses Jekyll and GitHub Pages.

The website is based on the open source
[al-folio](https://github.com/alshedivat/al-folio) academic theme.

Main pages include about, publications, news, and CV.

The CV content is managed in `_data/cv.yml`.

The publication list is managed in `_bibliography/papers.bib`.
